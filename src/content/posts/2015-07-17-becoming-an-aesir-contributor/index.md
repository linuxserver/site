Aesir is an attempt to make the unRAID interface visually stunning while at the same time making it accessible for new users and old alike.

It is a big project and so we would welcome any help from interested parties, there are several areas that people can help out with.

## Technologies Used

- SASS
- Codeigniter 3.0.0 ( With additional Modular Extensions HMVC )
- PHP 5.4+
- jQuery
- SQLite3

If you have any experience with these technologies and would like to get involved with the project then please contact us in #linuxserver.io on freenode.

You can get involved in many ways, including, but not limited to, translations, creating new plugins for the system, refactoring code to make it cleaner and more efficient, refactoring SASS to make it cleaner and more efficient, inline documenting the code functions, helping with design elements, working on core elements.

## Requirements

- **Being on IRC** – It is a requirement to be an official member of the Aesir team to maintain a presence on IRC, this is so we can collaborate on the project effectively.  If you don’t have an IRC client you can use this [web based chat client](https://kiwiirc.com/client/chat.freenode.net/#linuxserver.io)
- **Github account** – The code is maintained and version controlled on github, so you will need an account.
- There aren’t really any other requirements, if you are enthusiastic about the project and see an area you can help us with we would love to hear off you
